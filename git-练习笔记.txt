我的 Git 三步速查
=================

【日常上传】改完东西后，在工程目录里敲这三条
--------------------------------------------
git add .                        把这次所有改动挑出来，放进"暂存区"
git commit -m "说明改了什么"      打包成一次版本快照（存在本地）
git push                         把快照传到 GitHub


【三条命令的比喻】当作交作业就懂了
--------------------------------------------
git add     →  把要交的作业挑出来，放桌上
git commit  →  装订成册，写上日期和标题
git push    →  交到老师办公室


【关键理解】git 是"分布式"的
--------------------------------------------
本地就是一份完整仓库，你可以断网 commit 十几次，
最后一次 push 全部推上去。
所以 add / commit 是纯本地操作（断网也能做），
只有 push 需要联网。
这也是它和"网盘上传"最大的区别。


【最容易踩的坑】
--------------------------------------------
改完只敲 git push，什么都不会发生 —— 因为本地没有新提交。
必须先 commit，再 push。


【怎么确认真的传上去了】
--------------------------------------------
git log --oneline      看本地提交记录
git status             看还有没有没提交的改动
网页验证               点进仓库 → Commits
